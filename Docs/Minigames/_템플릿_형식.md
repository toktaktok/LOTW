## 3. 기능 명세

### 3.1 조작
쓸 수 있는 입력은 Navigate, Submit, Alt, Point, Click 다섯 가지다. Esc는 쓰지 않는다.

| 입력 | 키보드 / 마우스 | 동작 |
|---|---|---|
| Submit | | |

### 3.2 규칙
한 문장에 규칙 하나를 쓴다. 순서가 있으면 번호를 붙인다.

### 3.3 진행 변수
메카닉이 `Session.Vars`에 쓰는 값이다. 미니게임 문서의 결과 조건(`var:key>=n`)이 이 이름을 쓴다. 경과 시간 `time`(초)은 공통으로 있다.

| | | |
